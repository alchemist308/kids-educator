# Работа с «Квестоградом»

Используйте существующий checkout: облачная задача уже изолирована. Не создавайте Git worktree без явного запроса пользователя.

Node.js 24, npm, React/TypeScript/Vite, Netlify Functions, Netlify Blobs. Установка: `npm ci --cache /workspace/.cache/npm`. Не отключайте TLS, проверки целостности пакетов или тестовые утверждения.

Основные проверки: `npm run build`, `npm test`, `npm run test:e2e`. В этой среде браузерные тесты используют `/usr/bin/chromium`. `npm run dev` запускает интерфейс и локальные endpoints; после изменений серверного middleware перезапустите Vite. Локальные хранилища в памяти не переживают перезапуск. Production использует Netlify Blobs.

Учебные ответы должны быть однозначными и проверенными. Математика — 4 класс, подход Петерсон; русский/окружающий мир/литература — темы «Школы России». Не копируйте страницы учебников. Добавляя генератор, проверяйте смысл, падежи/согласование, четыре уникальных варианта и правильность объяснения. Перемешивание вариантов не должно менять идентичность задания или ответ.

XP: 8/12/16 за первое правильное решение по сложности; один вариант не награждается повторно. Пороги уровней растут на 25 XP. Достижения должны быть достижимы с доступным контентом. Прогресс двух профилей локален в браузере, не заявляйте синхронизацию между устройствами.

Для публикации используйте `npm run deploy`; пользователь уже запросил публикацию этого проекта в Netlify. Если нет доступа, завершите независимые проверки и сообщите конкретный блокер. Никогда не печатайте токены или окружение целиком; не записывайте секреты в Git. Production-проверка должна включать реальный запрос квеста и игру двух клиентов, а не только успешную сборку.
