# Квестоград

**Опубликованный сайт:** https://kvestograd.netlify.app

Семейный клуб обучающих приключений для двух четвероклассников. Пять миров знаний: математика, окружающий мир, русский язык, английский язык и литература.

Математика опирается на темы и подход программы Петерсон: закономерности, рассуждение, обратные действия, задачи в несколько шагов. Русский язык, окружающий мир и литература — на темы 4 класса «Школы России». Английский — базовые темы 4 класса; конкретный учебник не предполагается. Все задания авторские: это дополнительная практика, а не официальный цифровой учебник и не полное покрытие программы.

## Маршрут на год

52 недели по пять коротких квестов: один предмет в день, по 8 заданий за 10–15 минут. Всего **260 квестов и 2 080 учебных попыток на ребёнка**, включая повторение. Четыре этапа по 13 недель постепенно повышают сложность в пределах 4 класса. План — дополнительная практика с рекомендуемым годовым темпом; можно возвращаться к материалу и идти в своём ритме.

`src/data/curriculum.ts` содержит 52 недели и 49 тем. `year-questions.ts` подбирает задания по реальной теме недели: обычно шесть по текущей теме и два для повторения через одну и четыре недели. На неделях 13, 26, 39 и 52 проходят контрольные квесты по изученным темам. Годовой слот загружается через `POST /.netlify/functions/quest` с `{subject, week, level}`. Повторный запрос воспроизводим; завершение того же слота улучшает лучший результат, а число пройденных квестов растёт только один раз.

Литература включает 26 оригинальных текстов и 208 вопросов к ним. Текст изучается в течение двух недель: новые вопросы дополняются повторным обращением к прочитанному и проверенными вопросами о литературе. Годовой прогресс и пять больших достижений хранятся в `questograd-year`, отдельно для каждого игрока. Следующая рекомендуемая неделя начинается после всех пяти предметов текущей.

## Запуск

Нужен Node.js 24 (версия указана в `.nvmrc`).

```sh
npm ci
npm run dev
```

В облачной среде с недоступным домашним каталогом используйте `npm ci --cache /workspace/.cache/npm`. Дополнительные пароли для детской локальной игры не нужны. Локальный Vite обслуживает интерфейс и API квестов, дуэлей и семейного кабинета; данные сохраняются в памяти до перезапуска. Для проверки родительской активации задайте серверную переменную `PARENT_BOOTSTRAP` с `{hash,expiresAt}`: SHA-256 одноразового токена и срок действия в ISO. Сам токен передаётся ссылкой `/parent#activate=...`; он не попадает в frontend-переменные.

```sh
npm run build         # TypeScript и production-сборка
npm test              # контент, генератор, прогресс, API, гонки дуэлей, сценарий деплоя
npm run test:e2e      # браузерные сценарии с реальным локальным API
npm run preview       # production-клиент с локальным API
npm run test:production -- https://kvestograd.netlify.app  # реальный сайт и хранилище
```

Браузерные тесты в облачной среде используют установленный `/usr/bin/chromium`. На другом компьютере задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` на установленный Chromium. `E2E_BASE_URL` и `E2E_SERVER_COMMAND` позволяют проверить другой локальный порт или production-preview. Playwright автоматически готовит временную активацию родителя только для localhost/127.0.0.1; для всего набора используйте свежий локальный сервер. Персональная production-ссылка для тестов не нужна.

## Как устроены задания

`src/data/questions.ts` — проверенный начальный банк из 100 заданий: по 20 на предмет, с объяснениями. При первом запросе в Netlify он автоматически записывается в документ `questograd-content/questions-v1` в Netlify Blobs. Существующий банк имеет приоритет над исходным и никогда не перезаписывается автоматически. Новые данные проверяются по схеме; повреждённый банк сохраняется и выдаёт понятную ошибку.

`src/data/generator.ts` дополняет банк вычисляемыми вариантами: 16 семейств математических задач, 8 языковых семейств по русскому, 10 по английскому и 7 по окружающему миру. Правильные ответы и объяснения вычисляются из условий; генерация не требует платной модели или внешнего AI API. Это большой набор вариантов, а не бесконечное число разных учебных тем. Литература сочетает 20 проверенных вопросов о произведениях с 26 авторскими текстами и 208 заданиями на понимание прочитанного. Тексты и вопросы сохраняются отдельным документом `questograd-content/reading-v1`; существующие исправления в БД имеют приоритет над исходным материалом. Новые семейства добавляются в генератор отдельно.

Одиночный квест загружает 8 заданий через `POST /.netlify/functions/quest`. Уровень игрока влияет на распределение сложности в пределах 4 класса. В смешанном квесте есть все пять предметов. В API одиночной тренировки ответ передаётся браузеру для объяснений; этот режим не является защищённым экзаменом.

## Уровни и достижения

У двух профилей независимый опыт. За первое верное решение нового задания: **8 / 12 / 16 XP** по сложности. За ошибку и повтор уже решённого задания — 0 XP; ошибку можно исправить при следующей встрече. Уровни последовательно требуют **100, 125, 150, 175… XP**. Накопленный опыт не отнимается. Это начальная модель баланса: её можно корректировать по реальному темпу детей.

26 достижений: первые и идеальные квесты, изучение пяти миров, накопление опыта и три ступени освоения каждого предмета. Предметные достижения учитывают разные решённые задания. Для литературы пороги 5/10/20, для остальных предметов — 10/30/75. Пять годовых значков отмечают завершение 1, 4, 13, 26 и 52 недель. Дедупликация использует содержание задачи, а не случайный порядок ответов; вопросы к разным текстам имеют разные стабильные ID. Проверка идеального годового прохождения даёт примерно 32 уровня за 2 080 попыток, с постепенным замедлением роста.

Без подключения к семье профили, XP и достижения хранятся **локально в этом браузере**. После подключения по коду родителя они также сохраняются в приватном Netlify Blobs и синхронизируются между подключёнными устройствами. Очистка браузера удалит локальные данные и ключ устройства; для восстановления облачного прогресса потребуется новый код родителя. Хранятся последние 10 000 идентификаторов награждённых заданий; вытесненный очень старый вариант может снова дать опыт. Это семейная тренировка без публичного рейтинга.

## Кабинет родителя

На `/parent` доступны два детских профиля, уровни и XP, достижения, 260 годовых слотов, результаты по пяти предметам, дни и время занятий, серии активности, незавершённые и законченные квесты, ошибки с выбранным ответом и объяснением, результаты дуэлей. История фильтруется по ребёнку, предмету, датам и ошибкам; CSV выгружает все страницы выбранной истории. Подробная история ответов относится к одиночным квестам; для дуэлей сохраняется итог.

Первый вход — по персональной одноразовой ссылке: родитель задаёт пароль длиной 12–128 символов и игровые имена. Сервер хранит scrypt-хеш с солью; вход действует 8 часов через HttpOnly/Secure/SameSite=Strict cookie. Есть ограничение попыток входа. Доступ к статистике проверяется сервером при каждом запросе; детский ключ не открывает кабинет. Смена пароля завершает все родительские сеансы.

В разделе «Семья и доступ» родитель создаёт одноразовый восьмизначный код на 10 минут. На детском устройстве: профиль → «Прогресс для родителя» → код подключения. Пароль детям не требуется. Можно подключить до 20 устройств и отозвать доступ ненужных. Подключённое устройство доверенное: оно имеет доступ к обоим детским игровым профилям, но не к истории и управлению семьёй. Имена меняет родитель.

При подключении существующие счётчики объединяются консервативно по максимуму, идентификаторы награждённых заданий и годовые слоты — по объединению. Это не суммирует потенциально скопированный прогресс и не удваивает XP. Для двух разных старых браузеров точное восстановление отдельных попыток невозможно: раньше хранились только итоги. Даты, время и вопросы старых ответов не выдумываются; дашборд явно отмечает импортированные попытки. Новые ответы записываются с момента подключения. Офлайн-очередь переживает перезагрузку и повторяет отправку с теми же ID; новые XP не начисляются дважды. Вкладка в фоне не увеличивает время ответа; учитывается до 5 минут на вопрос. Дни в кабинете считаются по Москве.

Данные семьи хранятся в закрытом `kvestograd-family`: отдельные документы аккаунта, детей и подробной истории по дням. Условные записи с ETag защищают одновременную игру. Статистика обновляется каждые 30 секунд, отправка результатов — сразу и при восстановлении связи. Семейная тренировка доверяет устройствам и не предназначена для защищённых экзаменов. Подробная история сохраняется на год; лимит 50 000 событий на профиль существенно превышает 2 600 событий годового маршрута.

## Сетевые дуэли

Один игрок создаёт комнату и передаёт шестизначный код второму. Играть можно с разных устройств. Создатель выбирает предмет; оба получают один сохранённый набор из восьми вопросов и одинаковую сложность. Ответы проверяет сервер: 10 очков за верный, 0 за неверный, скорость не влияет на итог. Очки дуэли относятся только к комнате и не начисляют одиночный XP.

Комнаты живут 2 часа. В Netlify они хранятся в Blobs с сильной согласованностью, авторизацией токенами и условной записью по ETag: одновременные ответы не теряются, повторная отправка не даёт повторных очков, третий игрок не присоединится. Истёкшие комнаты перестают открываться; автоматическая очистка самих документов пока не настроена.

Не нужны фамилии, почта, камера или микрофон. Используйте игровые имена.

## Публикация

См. [инструкцию Netlify](docs/deployment.md). Сборка: `npm run build`; каталог публикации: `dist`; серверные функции: `netlify/functions`. Конфигурация включена в `netlify.toml`.

```sh
npm run deploy
```

Для этой команды нужен `NETLIFY_AUTH_TOKEN` в защищённой переменной среды; не записывайте его в исходники или чат. `NETLIFY_SITE_ID` необязателен: при отсутствии привязки будет создан новый сайт, его ID сохраняется в игнорируемом `.netlify/state.json`. Отдельные ключи базы данных в production не нужны.

После публикации проверьте загрузку квеста и дуэль с двух устройств: локальные проверки не подтверждают подключение production-хранилища. Активный тариф и лимиты запросов/хранилища определяются аккаунтом Netlify.
