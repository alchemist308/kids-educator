# Квестоград

Семейный клуб обучающих приключений для двух четвероклассников. Пять миров знаний: математика, окружающий мир, русский язык, английский язык и литература.

Математика опирается на темы и подход программы Петерсон: закономерности, рассуждение, обратные действия, задачи в несколько шагов. Русский язык, окружающий мир и литература — на темы 4 класса «Школы России». Английский — базовые темы 4 класса; конкретный учебник не предполагается. Все задания авторские: это дополнительная практика, а не официальный цифровой учебник и не полное покрытие программы.

## Запуск

Нужен Node.js 24 (версия указана в `.nvmrc`).

```sh
npm ci
npm run dev
```

В облачной среде с недоступным домашним каталогом используйте `npm ci --cache /workspace/.cache/npm`. Дополнительные пароли для локального запуска не нужны. Локальный Vite обслуживает и интерфейс, и реальные API квестов/дуэлей; банк и комнаты сохраняются в памяти до перезапуска.

```sh
npm run build         # TypeScript и production-сборка
npm test              # контент, генератор, прогресс, API, гонки дуэлей, сценарий деплоя
npm run test:e2e      # браузерные сценарии с реальным локальным API
npm run preview       # production-клиент с локальным API
```

Браузерные тесты в облачной среде используют установленный `/usr/bin/chromium`. На другом компьютере задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` на установленный Chromium. `E2E_BASE_URL` и `E2E_SERVER_COMMAND` позволяют проверить другой локальный порт или production-preview.

## Как устроены задания

`src/data/questions.ts` — проверенный начальный банк из 100 заданий: по 20 на предмет, с объяснениями. При первом запросе в Netlify он автоматически записывается в документ `questograd-content/questions-v1` в Netlify Blobs. Существующий банк имеет приоритет над исходным и никогда не перезаписывается автоматически. Новые данные проверяются по схеме; повреждённый банк сохраняется и выдаёт понятную ошибку.

`src/data/generator.ts` дополняет банк вычисляемыми вариантами: 16 семейств математических задач, 8 языковых семейств по русскому, 10 по английскому и 7 по окружающему миру. Правильные ответы и объяснения вычисляются из условий; генерация не требует платной модели или внешнего AI API. Это большой набор вариантов, а не бесконечное число разных учебных тем. Литература использует 20 проверенных заданий; её следует расширять новым авторским материалом в банке. Новые семейства добавляются в генератор отдельно.

Одиночный квест загружает 8 заданий через `POST /.netlify/functions/quest`. Уровень игрока влияет на распределение сложности в пределах 4 класса. В смешанном квесте есть все пять предметов. В API одиночной тренировки ответ передаётся браузеру для объяснений; этот режим не является защищённым экзаменом.

## Уровни и достижения

У двух профилей независимый опыт. За первое верное решение нового задания: **8 / 12 / 16 XP** по сложности. За ошибку и повтор уже решённого задания — 0 XP; ошибку можно исправить при следующей встрече. Уровни последовательно требуют **100, 125, 150, 175… XP**. Накопленный опыт не отнимается. Это начальная модель баланса: её можно корректировать по реальному темпу детей.

21 достижение: первые и идеальные квесты, изучение пяти миров, накопление опыта и три ступени освоения каждого предмета. Предметные достижения учитывают разные решённые задания. Для литературы пороги 5/10/20, для остальных предметов — 10/30/75. Дедупликация использует содержание задачи, а не случайный порядок ответов.

Профили, XP и достижения хранятся **локально в этом браузере**. Переноса между устройствами и аккаунтов пока нет. Очистка данных сайта удаляет прогресс. Хранятся последние 10 000 идентификаторов награждённых заданий; вытесненный очень старый вариант может снова дать опыт. Это семейная тренировка без публичного рейтинга.

## Сетевые дуэли

Один игрок создаёт комнату и передаёт шестизначный код второму. Играть можно с разных устройств. Создатель выбирает предмет; оба получают один сохранённый набор из восьми вопросов и одинаковую сложность. Ответы проверяет сервер: 10 очков за верный, 0 за неверный, скорость не влияет на итог. Очки дуэли относятся только к комнате и не начисляют одиночный XP.

Комнаты живут 2 часа. В Netlify они хранятся в Blobs с сильной согласованностью, авторизацией токенами и условной записью по ETag: одновременные ответы не теряются, повторная отправка не даёт повторных очков, третий игрок не присоединится. Истёкшие комнаты перестают открываться; автоматическая очистка самих документов пока не настроена.

Не нужны фамилии, почта, камера или микрофон. Используйте игровые имена.

## Публикация

См. [инструкцию Netlify](docs/deployment.md). Сборка: `npm run build`; каталог публикации: `dist`; серверные функции: `netlify/functions`. Конфигурация включена в `netlify.toml`.

```sh
npm run deploy
```

Для этой команды нужен `NETLIFY_AUTH_TOKEN` в защищённой переменной среды; не записывайте его в исходники или чат. `NETLIFY_SITE_ID` необязателен: при отсутствии привязки будет создан новый сайт, его ID сохраняется в игнорируемом `.netlify/state.json`. Отдельные ключи базы данных в production не нужны.

После публикации проверьте загрузку квеста и дуэль с двух устройств: локальные проверки не подтверждают подключение production-хранилища. Активный тариф и лимиты запросов/хранилища определяются аккаунтом Netlify.
